# Трофейный бэклог

Список PlayStation-игр на платину и 100% DLC: данные stratege.ru, оценки, кандидаты, недоделанное и статистика пройденного.

- Сайт: https://sergeybrenko.github.io/trophy-backlog/
- Открыть локально: `python3 -m http.server 8000` → http://localhost:8000
- Данные: `data/games.json`, `data/library.json`
- Быстро обновить статистику (свой профиль; трофеи, сложность, время платины и доли платин у игр «Списка» и «Кандидатов») и опубликовать: `./scripts/update.sh` (10–15 минут, нужны Python 3 с Pillow и доступ к push). Оценки, описания и DLC он не трогает.
- Полное обновление и правила ведения описаны в `CLAUDE.md` (для Claude Code). Достаточно написать ему «актуализируй».
